# AILGEN — קדימה. או מאחור.

האתר של AILGEN, סטודיו לבינה מלאכותית ואוטומציה לעסקים, יחד עם כל הפרויקטים שמוצגים בו.
הכול כאן סטטי: HTML, CSS ו-JavaScript בלי build, בלי תלויות ובלי שרת.

## מה יש בריפו

| תיקייה | מה זה |
|---|---|
| `index.html` | האתר הראשי של AILGEN: פתיחה עם חלקיקים, תיק עבודות עם עמודי פרויקט, סוכן AI, איילי המדריכה, טופס פנייה ומרכז בקרה |
| `assets/` | כל הווידאו והתמונות של האתר הראשי (48 קבצים) |
| `data/site.json` | תוכן האתר (כותרות, שירותים, שאלות נפוצות, מדיניות פרטיות, הצהרת נגישות). זה התוכן החי מתוך מרכז הבקרה |
| `switching-tv/` | סוויצ׳ינג TV: האתר החדש למסכי LED, עם מתכנן מסך, מבחן שמש, 19 מדריכים (`posts.json`), מסמכים משפטיים (`legal.json`) ומדיה מהשטח (`m/`) |
| `vermeil/` | VERMEIL: פרויקט קונספט לרשת בוטיק של יין ואלכוהול. עמוד אחד, בלי אף צילום |
| `brand/logo/` | הלוגו: סימן וסמליל כ-SVG (לבן וכחול), ולוחות PNG ברזולוציה מלאה לרקע כהה, לרקע בהיר ולאייקון |
| `brand/ads/` | מודעות פייסבוק ואינסטגרם: פיד 4:5, ריבוע 1:1 וסטורי 9:16, כקובצי HTML וכ-PNG מוכנים להעלאה (1080px) |
| `brand/source/` | קובצי המקור של לוחות העיצוב (`.dc.html`) ו-`canvas.json` |
| `campaigns/switching-tv/` | קמפיין "מבחן השמש" לסוויצ׳ינג TV: סרטון לריילס ולפיד, 5 מודעות סטטיות, טקסטים והמלצות הרצה. פרטים ב-[README של הקמפיין](campaigns/switching-tv/README.md) |

גיליון בניית הלוגו ותמונת המודעות על מסכי טלפון נמצאים ב-`assets/ailgen-logo-system.jpg` וב-`assets/ailgen-ads-context.jpg`.

## הרצה מקומית

```bash
python3 -m http.server 8000
```

ואז לפתוח את http://localhost:8000. צריך שרת ולא פתיחה ישירה של הקובץ, כי האתרים טוענים JSON עם `fetch`.

## העלאה לאוויר

זה אתר סטטי, אז אפשר להעלות אותו כמו שהוא ל-GitHub Pages, ל-Netlify, ל-Vercel או ל-Cloudflare Pages.
ב-GitHub Pages: Settings ← Pages ← Deploy from a branch ← לבחור את הענף ואת התיקייה `/ (root)`.

הקישורים בין האתרים יחסיים: כפתור "לאתר החדש" מוביל ל-`switching-tv/`, "לאתר החי" ל-`vermeil/`, והקרדיט ב-VERMEIL חוזר לאתר הראשי.

## מה עובד מחוץ ל-Claude

האתרים נבנו כ-Artifacts ב-Claude, ושם יש להם מסד נתונים, זיהוי משתמש ומודל שפה מובנים. מחוץ ל-Claude:

- **כל העיצוב, האנימציות, הווידאו, עמודי הפרויקטים, מתכנן המסך ומבחן השמש** עובדים במלואם.
- **תוכן האתר הראשי** נטען מ-`data/site.json`. כדי לשנות טקסט באתר, עורכים את הקובץ הזה.
- **סוכן ה-AI ויועץ ה-AI** עונים מתוך תשובות מוכנות מראש (לפי מילות מפתח) במקום מודל שפה. כדי שיענו באמת, צריך לחבר אותם ל-API של מודל דרך שרת קטן.
- **טפסי הפנייה ומרכזי הבקרה** צריכים מסד נתונים. בלי חיבור כזה, הטופס של AILGEN מציג "לא ניתן לשמור כרגע", והטופס של סוויצ׳ינג TV מציע לשלוח את הפנייה בוואטסאפ בלחיצה. כפתור מרכז הבקרה לא מופיע. לחיבור פשוט אפשר להשתמש ב-Formspree, ב-Supabase או בפונקציה קטנה שמעבירה את הפנייה למייל.
- **פרטי קשר:** הטלפון, האימייל והוואטסאפ של AILGEN ריקים ב-`data/site.json`. כשממלאים אותם, מופיעים כפתורי חיוג ווואטסאפ והקישורים בתחתית העמוד.

## הערות

- התמונות בסקשן "למי זה בנוי" ובפסי הצילום הן מ-Unsplash, והקרדיט לצלמים מופיע באתר עצמו.
- סוויצ׳ינג TV הוא עסק אמיתי. הטקסטים, המחירים והמפרטים נמשכו מהאתר הקיים שלו, וההדמיות מסומנות כהדמיות.
- VERMEIL הוא מותג בדוי. השם, המוצרים, המחירים והסניפים לא אמיתיים.
