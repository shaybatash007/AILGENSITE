# projects/

One folder per business, created by `.claude/skills/ailgen-studio/scripts/new-project.mjs`.

| File | What it is |
|---|---|
| `brief.md` | the brief: facts with sources, visitor doubts, the true claim, the concept, what only the owner can give |
| `brand.json` | the brand kit: concept, voice, palette tokens, type trio, logo, icons, mascot, site plan, campaign, honesty |
| `film.json` | the launch film for the engine (scenes, colours, fonts, motif, mascot, soundtrack mood) |
| `intake/` | for a URL: everything crawled from the existing site (texts, media, contacts, colours, fonts, screenshots) |
| `fonts/` | self-hosted woff2 + fonts.css (from `scripts/fonts.mjs`) |
| `demo/` | selected deliverables worth keeping in git |
| `out/` | render output (films, stills, review frames, soundtrack); not committed |

The three reference kits: `switching-tv/` (real client, from a URL), `ailgen/` (own brand, from a name),
`vermeil/` (concept, from a written idea).
