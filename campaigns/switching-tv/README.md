## לפני שמעלים

- **האתר החדש.** טיבי ומתכנן המסך ("3 שאלות, ואני יודע") קיימים באתר החדש, שנמצא בריפו הזה ב-`switching-tv/`. באתר שפעיל היום ב-switching.co.il עדיין אין אותם. עד שהאתר החדש עולה, כדאי שהכפתור יוביל לוואטסאפ, ולא לאתר.
- **הדמיות.** תמונות הבריכה, החצר, הקולנוע, חלון הראווה וחדר הישיבות הן הדמיות, ומסומנות "הדמיה" בסרטון ובמודעות, בדיוק כמו באתר. הסרטונים מהמסעדות והפיצריה הם צילומים אמיתיים, ומסומנים "מהשטח".
- **המספרים** נלקחו מהאתר: עד 6,500 NIT, טלוויזיה ביתית 400–600 NIT, IP65, התקנה ביום עבודה אחד, 3 שנות אחריות, 200+ פרויקטים ו-10 שנות ניסיון. אם משהו השתנה, מעדכנים ב-`source/reel.html` ומרנדרים מחדש.

## איך זה נבנה, ואיך משנים

הכול נבנה בקוד, בלי תוכנת עריכה. כל פריים מצויר על canvas לפי הזמן, ומקודד ל-H.264 עם ffmpeg.

```bash
cd source
python3 prep.py                      # מנקה את ההדמיות, מגדיל ומחלץ פריימים מהסרטונים מהשטח
python3 audio.py work/track.wav      # הפסקול (או --nomusic --ref-peak=1.164 לאפקטים בלבד)
node render.mjs --w 1080 --h 1920 --audio work/track.wav --out ../video/switching-reel-9x16.mp4
node render.mjs --w 1080 --h 1350 --audio work/track.wav --out ../video/switching-feed-4x5.mp4
node render.mjs --w 1080 --h 1350 --still sun-test-4x5,business-4x5 --dir ../static
node render.mjs --w 1080 --h 1920 --frames 3.7,5.8 --dir work/review   # פריימים בודדים לבדיקה
```

- `source/reel.html`: הסרטון והמודעות. פותחים ב-`reel.html?w=1080&h=1920&t=5.8` כדי לראות פריים בודד בדפדפן.
- `source/audio.py`: הפסקול והאפקטים, מסונכרנים לתזמונים של הסרטון.
- `source/render.mjs`: מרנדר ב-Playwright, במקביל על כמה ליבות, ומקודד עם ffmpeg.
- דרוש Node עם Playwright, ו-Python עם numpy, scipy ו-opencv.
