דומיינים: חדש או קיים

דומיין חדש

סיומות ‎.il נרשמות רק דרך רשמים שמוסמכים על ידי איגוד האינטרנט הישראלי. הלקוח הוא בעל הדומיין, ו-AILGEN היא איש הקשר הטכני. בדוק אם לרשם שתבחר יש תוכנית משווקים או API, כדי שהרישום יהיה שלב בתהליך ההזמנה ולא עבודה ידנית.

דומיין קיים

ב-Cloudflare Pages, תת-דומיין כמו www מתחבר ברשומת CNAME אל <project>.pages.dev. הדומיין הראשי (בלי www) דורש להעביר את שרתי השמות ל-Cloudflare. לפני המעבר מעתיקים את רשומות המייל (MX) ואת רשומות ה-TXT, כדי שהמייל לא ייפגע. חלופה: הפניה מהדומיין הראשי ל-www אצל ספק ה-DNS הנוכחי.

חוק ואחריות

  • תיקון 13 לחוק הגנת הפרטיות (בתוקף מ-14 באוגוסט 2025): הודעה ברורה בנקודת האיסוף, הסכמה מפורשת ונפרדת, קישור למדיניות ליד כפתור השליחה, ובלי "דפוסים אפלים". הטפסים שבנינו עומדים בזה: תיבת אישור שלא מסומנת מראש, וקישור למדיניות בתוך הטופס.
  • AILGEN מעבדת מידע בשם הלקוחות (הפניות שלהם). צריך הסכם עיבוד מידע בכל חוזה.
  • נגישות: האתרים נבנים לפי ת"י 5568 ו-WCAG AA, עם תפריט נגישות והצהרה. הלקוח צריך למלא את פרטי רכז הנגישות.
  • אמת: תוויות "מהשטח" ו"הדמיה", בלי המלצות או מספרים מומצאים, וגילוי שהמוקד הדיגיטלי הוא AI. זה גם הגנה משפטית וגם יתרון מכירה.
  • בעלות: האתר, התוכן והדומיין שייכים ללקוח. AILGEN שומרת את המנועים והשיטה.

מה עליך להקים

  • אישור מטלאור כראדי להציג את האתר, לפרסם אותו ולהשתמש בו בתיק העבודות. אחרי זה: קישור תצוגה, חיבור לדומיין, הרצת הקמפיין.
  • עוסק מורשה או חברה, ורואה חשבון (מע"מ, חשבוניות עם מספר הקצאה).
  • ספק סליקה עם הוראות קבע, עמוד תשלום מתארח ו-webhook.
  • שירות חשבוניות שמפיק מספרי הקצאה, מחובר לסליקה.
  • חשבון Cloudflare (Pages ו-Workers בתשלום, 5$ בחודש) וארגון GitHub לאתרי הלקוחות.
  • מפתח Claude API (Console) לסוכנים באתרי הלקוחות, עם מגבלת הוצאה חודשית.
  • חשבון אצל רשם ‎.co.il מוסמך, אם אפשר עם תוכנית משווקים.
  • מסמכים: תנאי שירות, מדיניות פרטיות ל-AILGEN, הסכם עיבוד מידע, ואישור שימוש בעבודה לתיק העבודות. כדאי שעורך דין יעבור עליהם.
  • ערוץ תמיכה (וואטסאפ עסקי או מייל) ופרטי קשר לגיבוי במרכז הבקרה של עמוד הסטודיו.

הפרומפט המשודרג

תפקיד: אתה הסטודיו של AILGEN. בונה עסק דיגיטלי שלם ללקוח אמיתי, ובאותה ריצה מודד ומשפר את המכונה שבונה אותו, כדי שתהפוך למוצר שכל אחד יכול לקנות.

ללקוח: אתר חדש ברמה של סוויצ׳ינג ו-AILGEN (קונספט מהלוגו, כלי הוכחה, מרכז בקרה, סוכן, נגישות), זהות (סמל בווקטור, פאביקון, פלטה, פונטים), סרטון השקה 9:16 ו-4:5 עם פסקול, 3 מודעות וקופי. אמת לפני וואו.

למוצר: מדידה של זמן, טוקנים וכסף לכל שלב מתוך הלוג; מה מאט ומה מאיצים בלי לפגוע באיכות; תקציבים ושערים; איך לקוח מזמין, רואה את היצירה, משלם, קונה או מחבר דומיין; עמוד מוצר חי באתר של AILGEN; דוח אחד שאפשר לשלוח לשותף.

מוכן כש: כל שער עובר, המספרים יוצאים מהמדידה, האתרים נפתחים בלי שגיאות בנייד ובדסקטופ, והסרטון נצפה עד הסוף עם סאונד.
